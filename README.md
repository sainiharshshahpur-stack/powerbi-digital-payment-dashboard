# Power BI Digital Payment Transaction Analytics Dashboard

## Project Overview
This project presents an interactive Power BI dashboard for analyzing digital payment transactions and user behavior.

## Key Metrics
- Total Transaction Value: 3.47 Billion
- Total Transactions: 300K
- Success Rate: 96%
- Total Users: 108K

## Dashboard Features
- Monthly Transaction Analysis
- Age Segment Analysis
- Service-wise Transaction Analysis
- Weekday vs Weekend Analysis
- KPI Monitoring and Reporting

## Tools Used
- Power BI
- Power Query
- DAX
- Data Analytics

## Project Insights
- Identified transaction trends across months.
- Analyzed user activity by age segment.
- Compared transaction volumes across services.
- Evaluated weekday and weekend transaction patterns.
